# IRONLOG

IRONLOG — кроссплатформенный дневник тренировок на Flutter (Android/iOS).

## Что уже реализовано в стартовом MVP
- Тёмная тема и кислотно-зелёный акцент.
- Календарь с отметками тренировочных дней.
- Создание тренировки на выбранную дату.
- Добавление упражнений и отдельных подходов (вес × повторения).
- История тренировок и удаление записей.
- Базовая статистика и график активности за 7 дней.
- Локальное сохранение записей через SharedPreferences.

## Запуск
1. Установить Flutter SDK и Android Studio (для Android).
2. Распаковать архив.
3. В терминале из папки `ironlog` выполнить:
   ```bash
   flutter create . --platforms=android,ios
   flutter pub get
   flutter run
   ```
4. Для iOS-сборки нужен macOS с Xcode. На Windows можно разрабатывать и собирать Android APK, но нативную iOS-сборку выполнить нельзя.

## Облачная синхронизация и вход
В `pubspec.yaml` уже добавлен `supabase_flutter`, а схема базы находится в `supabase/schema.sql`.
Для включения реальной регистрации Email/Google/Apple и синхронизации нужно:
1. Создать проект Supabase.
2. Выполнить SQL из `supabase/schema.sql` в SQL Editor.
3. Настроить OAuth-провайдеры Google и Apple в Supabase и соответствующих консолях.
4. Передать в приложение URL проекта и anon/publishable key через безопасную конфигурацию.

Облачная авторизация намеренно не имитируется: до подключения собственного проекта Supabase кнопки входа не должны выдавать ложный результат. Пока MVP хранит данные локально на устройстве.

## Важно
Это исходный проект первой версии, а не готовый подписанный APK. В текущей среде Flutter SDK не установлен, поэтому компиляция и проверка запуска здесь не выполнялись.


## Автоматическая сборка APK через GitHub Actions
1. Создай репозиторий на GitHub (например, `ironlog`).
2. Распакуй архив и загрузи все файлы и папки **внутри папки ironlog** в корень репозитория. Обязательно сохрани `.github/workflows`.
3. Открой вкладку **Actions**. Если GitHub попросит включить Actions — разреши.
4. Выбери **Build IRONLOG APK** → **Run workflow**. Сборка также запускается автоматически при отправке изменений в `main` или `master`.
5. После завершения открой запуск и скачай артефакт **ironlog-android-apk** в разделе Artifacts. Внутри будет `app-release.apk`.

Нужен аккаунт GitHub и доступ к репозиторию. Сборка выполняется на серверах GitHub; первый запуск может занять несколько минут.
